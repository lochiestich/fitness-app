# fitness-app — system map

A change-impact map of the Training Log PWA at repo root: what the nouns are, how they move, and what breaks if you touch one. The subject repo is the source of truth — this map cites it, never restates it. Start here, not by reading the whole tree.

## Where things live

| Folder | What it holds |
|---|---|
| `CONTEXT.md` | how to walk this map, the universes, name collisions (read this first) |
| `_meta/schema.md` | the closed set of card types and labels |
| `_templates/` | blank `object.md` / `process.md` starters — copy, don't freehand |
| `objects/` | one card per noun cluster — `_index.md` lists all of them, stub or verified |
| `processes/` | one card per real, repeating movement (4 of them) |
| `effects/CONTEXT.md` | "if you're changing X, open these cards" |

## Route by what you're trying to do

| If | Go to | Then stop at |
|---|---|---|
| orienting for the first time | `CONTEXT.md` | the universes + name collisions |
| "what is X" (a type, a module, a screen) | `objects/_index.md` → the matching cluster card | that card's Shape + Connected to |
| "what breaks if I change X" | `effects/CONTEXT.md` | the cards it names, in order |
| "how does logging/derived-display/backup/deploy actually run" | `processes/` | the one matching card |
| the data model or a formula (volume, e1RM, fatigue, pace) | repo-root `SPEC.md` §3–5 | don't duplicate it into a card |
| stack, conventions, hard rules (no network, store.ts-only, etc.) | repo-root `CLAUDE.md` | don't duplicate it here either |

## The one rule

This map is generated by walking the repo, not the other way around. If a card and the source disagree, the source wins and the card is stale — fix the card, don't trust it over the code.
