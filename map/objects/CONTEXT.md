# objects/ — the nouns

One card per noun cluster, not per file. A cluster is "how an editor would ask about it" — e.g. every type in `src/types.ts` is one `data-model` cluster, not seven separate cards, because nobody asks "what is `LiftSet`" in isolation from `DB`/`Session`/`Exercise`.

`_index.md` lists every cluster with its status. Read the index before opening a card — don't open a card to find out it's a stub.

New cluster: copy `_templates/object.md`, fill the frontmatter, add a line to `_index.md` in the same edit. A cluster that's just a stub line with no folder yet is fine — don't create the folder until there's a body to put in it.
