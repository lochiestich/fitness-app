# Training Log

A personal training tracker for lifting, cardio and polo. Installed on a phone, stores everything on device, works with no signal.

See `SPEC.md` for the data model and build order, and `CLAUDE.md` for stack and conventions.

## Commands

```bash
npm run dev      # local
npm run build    # production build
npm run preview  # test the built PWA locally
npm run deploy   # build and push to gh-pages
```
